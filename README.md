Smartestate AI

Полезный инструмент для тех, кто ищет или планирует найти себе жилье. Smartestate AI анализирует рынок, предсказывает стоимость недвижимости и помогает пользователю в поиске выгодных объявлений

-необходимо установить зависимости requests, beautifulsoup4 и pandas
-для запуска программы, необходимо ввести в директории, где установлена программа комманду "python smartestateai.py"
